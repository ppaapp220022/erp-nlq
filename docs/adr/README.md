# ADR (결정 기록)

되돌리기 어렵거나 "왜 이렇게 했나"를 질문받을 만한 결정을 하나에 한 파일로 남긴다. 미리 보고 막은 위험도 여기에 적는다. 실제로 부딪힌 문제는 구글 드라이브 troubleshooting 폴더(비공개)에 적는다.

파일 이름은 `NNNN-짧은-제목.md`로 한다.

```markdown
# NNNN. 제목

- 상태: 제안 | 채택 | 대체됨(→ NNNN)
- 날짜: YYYY-MM-DD

## 맥락
무엇을 정해야 했고, 어떤 제약이 있었나.

## 결정
무엇을 골랐나.

## 고려한 대안
대안마다 고르지 않은 이유.

## 결과
이 결정으로 생기는 것과 감수하는 것. 근거가 된 소스·문서 링크.
```
