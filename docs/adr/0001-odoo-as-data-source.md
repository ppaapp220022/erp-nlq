# 0001. 데이터 소스로 Odoo Community 19

- 상태: 채택
- 날짜: 2026-11-03

## 맥락

이 프로젝트에는 실제 업무 흐름(판매·구매·재고·회계)과 역할·행 단위 권한 모델을 갖춘 ERP 데이터가 필요하다. 목표는 그 위에 질의 계층을 만드는 것이다. ERP 프레임워크 자체를 익히는 데 시간을 쓰지 않아야 한다.

## 결정

Odoo Community 19.0(LGPL-3.0)을 공식 Docker 이미지로 띄우고 데모 데이터를 쓴다. Odoo 코드는 수정하지 않는다. DB에는 질의용 읽기 전용 역할과 (M6) RLS 정책만 더한다.

## 고려한 대안

- **ERPNext:** Frappe 프레임워크 위에서 돈다. 데이터를 제대로 읽으려면 DocType, `tab` 접두사 테이블, Frappe 권한 모델부터 배워야 한다. 기본 DB가 MariaDB라 pgvector와 Postgres RLS를 쓸 수 없고, 권한 강제 비교 실험이 구문 트리 방식 하나로 줄어든다.

## 결과

- PostgreSQL이라 검색은 pgvector로 붙이고, 권한 강제는 구문 트리 재작성과 RLS 두 방식으로 비교할 수 있다.
- 띄우는 데 공식 이미지 두 개면 된다.
- 감수하는 것: 공식 이미지 `odoo:19.0` 태그는 매일 새 빌드로 바뀐다. 재현성을 위해 digest를 고정한다(M1).
- 감수하는 것: Odoo 19 Enterprise에는 내장 AI 질의 기능이 있다. 이 프로젝트는 Community 위에서 권한 안전성을 측정하는 쪽으로 차별화한다.
- ORM API 대신 SQL을 택한 이유는 [ADR 0008](0008-sql-over-orm-api.md)에 있다.
